# TOTM Overlay

TOTM Overlay is a Foundry VTT module for theater-of-the-mind play with a Fabula Ultima / JRPG-style presentation.

It adds:

- cinematic scene backgrounds with saved framing
- player cards with HP / MP / IP / FP display
- encounter management with stage enemies and enemy bar targeting
- NPC and encounter libraries
- shared player / GM pins
- quest pins
- per-background props
- clock integration
- optional PopOut! compatibility for the library and picker windows

## Foundry Version

- Foundry VTT v13

## Recommended Setup

- System: `projectfu`
- Optional modules:
  - `global-progress-clocks`
  - `popout`

## Installation

Once you publish this module to GitHub, replace the placeholder URLs in your release manifest and use the raw `module.json` URL in Foundry's module installer.

## Release Notes

Before publishing:

1. Upload the module contents as a release zip.
2. Update the manifest URLs in `module.release-template.json`.
3. Copy those final URL fields into `module.json` if you want the checked-in manifest to be the public release manifest.
