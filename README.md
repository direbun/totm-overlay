# TOTM Overlay

TOTM Overlay is a Foundry VTT module for theater-of-the-mind play with a Fabula Ultima / JRPG-style presentation.

It adds:

- cinematic scene backgrounds with saved framing
- player cards with HP / MP / IP / FP display
- encounter management with stage enemies and enemy bar targeting
- NPC and encounter libraries
- shared player / GM pins
- quest pins
- per-background props
- clock integration
- optional PopOut! compatibility for the library and picker windows

## Foundry Version

- Foundry VTT v13
- Current module version: `3.0.0`

## Recommended Setup

- System: `projectfu`
- Optional modules:
  - `global-progress-clocks`
  - `popout`

## Installation

Use this manifest URL in Foundry's module installer:

`https://github.com/direbun/totm-overlay/releases/latest/download/module.json`
